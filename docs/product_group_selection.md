# Product group selection protocol

Do not select a category based only on the highest sales volume. Rank candidate groups using:
1. Date coverage and continuity.
2. Number of stores and SKUs represented.
3. Completeness of matching inventory observations.
4. Demand intermittency and variability.
5. Sufficient history for time-based forecasting evaluation.

Prefer Subcategory as the initial analysis grain, then narrow to a stable product group if the data supports it. Confirm that stock observations can be aligned with sales at the same store-SKU-date grain. The final selection must be based on observed CSV values, not assumptions about the retailer's assortment.
